## Bloque 3 · Ingeniería mecánica y diseño 3D
*Claude + Python como co-piloto de tus herramientas de diseño.*

**Flujo agentico:** Instrucción natural → Claude razona → Python ejecuta → Software actúa → Feedback a Claude

| Módulo | Resumen | Conceptos clave |
|---|---|---|
| 🟠 Claude + Blender | Agente que opera Blender vía `bpy`. Geometría, materiales y render por instrucción. | bpy API, Geometría paramétrica, Render batch, Scripting agentico |
| 🔵 Claude + SolidWorks | Agente que controla SolidWorks vía COM API. Diseño paramétrico y planos. | win32com, Diseño paramétrico, Configuraciones, Export DXF/STEP |
| 🟣 Claude + Fusion 360 | Agente que diseña en Fusion 360 vía Python API. Sketches y variantes. | Fusion API, Sketches auto, Variantes paramétricas, Export STL/STEP |
| 🤖 Agente Python agentico | El bucle completo: Claude planifica, Python ejecuta, el resultado vuelve a Claude. | anthropic SDK, Tool use, Bucle plan→ejecutar→corregir, Error handling |

## Ruta de aprendizaje

1. **Nivel 1 · Conversación efectiva** — prompts claros, contexto, instrucciones directas
2. **Nivel 2 · Técnicas avanzadas** — few-shot, chain-of-thought, roles de experto
3. **Nivel 3 · Python + API** — SDK de Claude, herramientas, bucles agenticos
4. **Nivel 4 · Agente de ingeniería** — Claude opera Blender, SolidWorks, Fusion 360
5. **Nivel 5 · Sistema empresarial** — compras, CRM y contabilidad integrados
